# InfoFP-Pacman
Pacman game for Functioneel Programmeren by Coen and Alice

# Game Instructions
The game is classic asteroids.
You can shoot using spacebar, rotate using the left and right arrow keys, and move forwards using the up key.
The game can be pause using P, and on the Game Over screen you can restart using R or continue on using C.
The goal is to earn as many points as possible by shooting the asteroids, upon destroying all enemies on screen, a new round of asteroids will spawn.
The more points you have the more saucers will spawn and the harder the saucers become.
